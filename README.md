# Pegboard planners

Layout configurators for the modular Skadis pegboards by Adam Kozak ([@adamkozak](https://makerworld.com/en/@adamkozak) on MakerWorld).

## Live planners

- **Snapmaker 5.2 mm** – https://adamkozakgrafika.github.io/pegboard-planner/snapmaker/
- **Skadis 4.0** – https://adamkozakgrafika.github.io/pegboard-planner/4.0/

Pick the board size, get the layout and the list of plates to print. The layout is stored in the link, so you can share a ready board with anyone.

Each planner is a single HTML file with no dependencies (apart from Google Fonts).
